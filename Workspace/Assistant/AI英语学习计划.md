# AI 英语学习计划

> 目标：每天 10~15 分钟，积累 AI 领域核心词汇，提升阅读英文文档和论文的能力。
> 来源：AI 英文博客、论文、文档中高频出现的词汇。

---

## 📅 学习计划（共 8 周）

每周一个主题，每天复习 + 学习新词，第 8 周综合巩固。

---

## Week 1：机器学习基础

**核心词汇：**

| 单词 | 音标 | 中文含义 | 例句 |
|------|------|----------|------|
| algorithm | /ˈælɡərɪðəm/ | 算法 | A neural network is a type of **algorithm**. |
| dataset | /ˈdeɪtəˌset/ | 数据集 | The **dataset** contains 10,000 images. |
| training | /ˈtreɪnɪŋ/ | 训练 | **Training** a model requires lots of data. |
| inference | /ˈɪnfərəns/ | 推理 | The model performs **inference** in real time. |
| label | /ˈleɪbəl/ | 标签 | Each image has a corresponding **label**. |
| feature | /ˈfiːtʃər/ | 特征 | The network learns to extract **features**. |
| gradient | /ˈɡreɪdiənt/ | 梯度 | We use **gradient** descent to optimize. |
| epoch | /ˈiːpɒk/ | 轮次 | One **epoch** means one pass through the data. |
| batch | /bætʃ/ | 批次 | We process data in **batches** of 32. |
| overfit | /ˌəʊvəˈfɪt/ | 过拟合 | The model **overfits** when it memorizes data. |

**每日任务（10分钟）：**
1. 背诵当天 5 个单词（3分钟）
2. 用每个单词造一个句子（5分钟）
3. 第二天复习前一天单词（2分钟）
