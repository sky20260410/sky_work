## 三、软件准备

### 1. 安装 Arduino IDE

下载地址：https://www.arduino.cc/en/software

选择对应操作系统版本，安装后打开。

### 2. 添加 ESP32 开发板

1. 打开 Arduino IDE → 文件 → 首选项
2. 在"附加开发板管理器网址"中添加：
   ```
   https://dl.espressif.com/dl/package_esp32_index.json
   ```
3. 打开 工具 → 开发板 → 开发板管理器
4. 搜索 "ESP32" → 安装

### 3. 选择开发板

工具 → 开发板 → ESP32 Arduino → **ESP32 Dev Module**

## 四、学习路线（4步走）

### 🟢 第一步：让灯亮起来（10分钟）

**目标**：控制 GPIO2 的 LED 亮灭

```cpp
// 第一个程序：点亮板载LED
void setup() {
  pinMode(2, OUTPUT);          // 设置GPIO2为输出模式
}

void loop() {
  digitalWrite(2, HIGH);       // 点亮LED
  delay(1000);                 // 等待1秒
  digitalWrite(2, LOW);        // 熄灭LED
  delay(1000);                 // 等待1秒
}
```

**知识点**：
- `pinMode()` — 设置引脚模式
- `digitalWrite()` — 输出高低电平
- `delay()` — 延时函数（毫秒）

---

### 🟡 第二步：让3个灯轮流亮起（15分钟）

**目标**：在面包板上连接3个LED，实现流水灯

**接线图说明**：

```
ESP32 GPIO2  ──────┤220Ω├──── LED1（红） ──────� GND
ESP32 GPIO4  ──────┤220Ω├──── LED2（黄） ──────� GND
ESP32 GPIO5  ──────┤220Ω├──── LED3（绿） ──────┐
                                              │
                                            GND
```

**代码实现**：

```cpp
const int LED_PINS[] = {2, 4, 5};  // 红、黄、绿对应的GPIO口
const int LED_COUNT = 3;

void setup() {
  for (int i = 0; i < LED_COUNT; i++) {
    pinMode(LED_PINS[i], OUTPUT);
  }
}

void loop() {
  // 流水方向：第1个→第2个→第3个→循环
  for (int i = 0; i < LED_COUNT; i++) {
    digitalWrite(LED_PINS[i], HIGH);   // 当前灯亮
    delay(300);                         // 亮300ms
    digitalWrite(LED_PINS[i], LOW);    // 当前灯灭
  }
}
```

**知识点**：
- 数组的使用
- for 循环控制顺序
- 限流电阻的作用

### 🔵 第三步：加入可调参数（10分钟）

```cpp
const int LED_PINS[] = {2, 4, 5};
const int LED_COUNT = 3;

int delayMs = 300;   // 可调整速度：调大=变慢，调小=变快

void setup() {
  for (int i = 0; i < LED_COUNT; i++) {
    pinMode(LED_LED_PINS[i], OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < LED_COUNT; i++) {
    digitalWrite(LED_PINS[i], HIGH);
    delay(delayMs);
    digitalWrite(LED_PINS[i], LOW);
  }
}
```

**亲子互动**：让孩子修改 `delayMs` 的数值，观察灯光速度变化

## 六、常见问题排查

| 现象 | 可能原因 |
|------|---------|
| LED 不亮 | 接线松动、GPIO口选错、接线正负极反了 |
| 编译报错 | 代码有拼写错误、引脚号写错 |
| ESP32 连接不上 | USB线不是数据线（仅充电线不行）、驱动未安装 |
| 灯一直亮不灭 | 代码中 `digitalWrite(LOW)` 写成了 HIGH |
